## Metodología de Desarrollo en V: Fase de Verificación (Rama Descendente)

Este proyecto se desarrolla siguiendo la **Metodología de Desarrollo en V**, un modelo secuencial que enfatiza la verificación y validación constante. A continuación, se describe la **Rama Descendente (Fase de Verificación)**, la cual utilizaremos como hoja de ruta para planificar y estructurar nuestra aplicación web:

### 1. Análisis de Requisitos (Requirement Gathering)
En esta fase inicial, definimos las necesidades del usuario final y las funcionalidades básicas que el sistema debe cumplir. 
* **Objetivo:** Responder a la pregunta *¿Qué debe hacer el sistema?* (ej. Un sistema web para gestión de manufactura digital 3D).
* **Entregable:** Especificación de requisitos.

### 2. Análisis del Sistema (System Analysis)
Traducimos los requisitos de los usuarios en especificaciones técnicas, definiendo el comportamiento general del software y su arquitectura funcional.
* **Objetivo:** Comprender las reglas de negocio y cómo interactúan las partes del sistema.

### 3. Diseño de Software / Arquitectura (Software Design)
Se definen los componentes principales, las interfaces y se selecciona el stack tecnológico que soportará el proyecto.
* **Stack Tecnológico Seleccionado:** 
  * Backend: Python + Django
  * Frontend: Vite.js
  * Infraestructura: Docker
  * Control de Versiones: GitHub

### 4. Diseño de Módulos (Module Design)
Es el diseño detallado. Aquí se especifica la lógica interna, los algoritmos y los modelos de bases de datos para cada módulo de la aplicación.
* **Objetivo:** Estructurar componentes como la App de Autenticación (registro, login/logout), definiendo sus tablas y flujos.

### 5. Punto de Inflexión
Representa el final de la fase de planificación y diseño descendente, marcando la transición hacia la construcción real del sistema.

### 6. Codificación (Coding)
La fase de ejecución donde el diseño se transforma en código fuente.
* **Actividades actuales:** Configuración del entorno (Docker, GitHub), inicialización del proyecto en Django, creación de la App de Autenticación y configuración del Django Admin.
